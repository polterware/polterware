# Historical specification archive

This directory preserves superseded specifications and intermediate implementation plans for historical reference.

Nothing here is normative for current behavior or future product direction. Documents may intentionally describe fixture-only stages, removed navigation, abandoned repository layouts, or capabilities that were never implemented.

Current authority lives outside this directory:

- [`../spec.md`](../spec.md) defines implemented behavior.
- [`../product-vision.md`](../product-vision.md) defines product direction.
- [`../adr/`](../adr/) records accepted architecture decisions.
- [`../../.specify/memory/constitution.md`](../../.specify/memory/constitution.md) defines repository governance.

Do not update archived specifications merely to match the current product. Move a historical document back into active documentation only through an explicit specification or ADR change.
