# Prototype composition notes

Source: `prototype/*.png` (guide only, not pixel-perfect)

1. **Shell**: Dark app chrome; left sidebar blends with window; content sits in one large rounded MainSurface.
2. **Sidebar**: Grouped sections (CORE / INSIGHTS / CONFIGURATION); compact icons + labels; neutral active pill; footer with core status + actor.
3. **Density**: Compact type; tight row height; sparse borders (`white` ~5–14% alpha).
4. **Resources index**: Page title + env chip + search/filters; dense table (name, type, env, provider, status, last sync); no right inspector.
5. **Resource detail**: Breadcrumb; identity header; status chips; overview list; linked architecture; activity; quick actions — full page.
6. **Architecture canvas**: Layer bands (Cloud / Applications / Data); quiet nodes; subtle edges; zoom controls; selection = light border only.
7. **Node detail**: Same page grammar as resource detail + relationship mini-map.
8. **Brand green**: Status dots / rare accents only — never nav fill or large surfaces.
9. **Avoid**: Card stacks, glass blur, cyberpunk glow, Linear branding copy.
