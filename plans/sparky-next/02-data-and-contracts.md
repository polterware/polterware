# Data model and contracts

W0-CONTRACTS turns this document into: `sparky/backend/providers/sqlite/migrations/0001_baseline.sql`, the protos under
`sparky/schemas/sparky/v1/`, the Go ports (interfaces) in each `domains/<x>`, and the MCP tool JSON schemas. Treat the
statements below as the **specification**; fix mistakes via the request flow, not silently.

## Conventions

- IDs: ULID strings (26 chars, Crockford base32), generated by the core (`platform/ids`).
- Timestamps: UTC RFC 3339 with milliseconds (`2026-10-03T21:30:00.000Z`) in SQLite TEXT columns and on the wire
  (`google.protobuf.Timestamp` in protos, ISO strings in MCP). Calendar dates without time use `YYYY-MM-DD`.
- `rev INTEGER` starts at 1, +1 on every write of the row. `updated_at` is set by the service, never by the client.
- Booleans are `INTEGER 0/1`. All tables `STRICT`. `PRAGMA journal_mode=WAL; foreign_keys=ON; busy_timeout=5000;
  synchronous=NORMAL`.
- Migrations: forward-only, numbered, applied at core start; **one clean baseline**, no compatibility with Swift data.
- Enumerations are lowercase strings validated by `CHECK` and by the domain.

## SQL baseline (`0001_baseline.sql`)

```sql
CREATE TABLE minds (
  id TEXT PRIMARY KEY,
  parent_id TEXT REFERENCES minds(id) ON DELETE CASCADE,       -- deleting a Mind deletes its descendants
  name TEXT NOT NULL CHECK (length(name) BETWEEN 1 AND 120),
  color TEXT,                                                   -- '#RRGGBB'
  icon TEXT,                                                    -- Hugeicons name
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, rev INTEGER NOT NULL DEFAULT 1
) STRICT;
CREATE INDEX minds_parent ON minds(parent_id, sort_order);

CREATE TABLE memories (
  id TEXT PRIMARY KEY,
  mind_id TEXT REFERENCES minds(id) ON DELETE SET NULL,         -- NULL = Inbox; memories survive Mind deletion
  title TEXT NOT NULL CHECK (length(title) BETWEEN 1 AND 500),
  note TEXT NOT NULL DEFAULT '',                                -- Markdown
  status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','completed')),
  pinned INTEGER NOT NULL DEFAULT 0,
  priority INTEGER CHECK (priority BETWEEN 0 AND 3),            -- NULL none; 1 low .. 3 high; 0 reserved
  due_at TEXT, due_all_day INTEGER NOT NULL DEFAULT 0,
  sort_order INTEGER NOT NULL DEFAULT 0,
  auto_complete_on_checklist INTEGER NOT NULL DEFAULT 0,
  completed_at TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, rev INTEGER NOT NULL DEFAULT 1
) STRICT;
CREATE INDEX memories_mind ON memories(mind_id, status, sort_order);
CREATE INDEX memories_status_updated ON memories(status, updated_at DESC);
CREATE INDEX memories_due ON memories(due_at) WHERE due_at IS NOT NULL;
CREATE INDEX memories_pinned ON memories(pinned) WHERE pinned = 1;

CREATE TABLE tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL COLLATE NOCASE UNIQUE CHECK (length(name) BETWEEN 1 AND 60),
  color TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL, rev INTEGER NOT NULL DEFAULT 1
) STRICT;
CREATE TABLE memory_tags (
  memory_id TEXT NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
  tag_id TEXT NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (memory_id, tag_id)
) STRICT;
CREATE INDEX memory_tags_tag ON memory_tags(tag_id);

CREATE TABLE check_items (
  id TEXT PRIMARY KEY,
  memory_id TEXT NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
  title TEXT NOT NULL CHECK (length(title) <= 500),
  detail TEXT NOT NULL DEFAULT '',
  done INTEGER NOT NULL DEFAULT 0,
  sort_order INTEGER NOT NULL DEFAULT 0,
  completed_at TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
) STRICT;
CREATE INDEX check_items_memory ON check_items(memory_id, sort_order);

CREATE TABLE schedules (                                        -- 1:1 with memories
  memory_id TEXT PRIMARY KEY REFERENCES memories(id) ON DELETE CASCADE,
  active INTEGER NOT NULL DEFAULT 1,
  fire_at TEXT NOT NULL,                                        -- instant of the FIRST occurrence (UTC)
  tz TEXT NOT NULL,                                             -- IANA zone the wall-clock rules are evaluated in
  all_day INTEGER NOT NULL DEFAULT 0,
  freq TEXT CHECK (freq IN ('minutely','hourly','daily','weekly','monthly','yearly')),   -- NULL = one-shot
  every INTEGER NOT NULL DEFAULT 1 CHECK (every >= 1),
  weekday_mask INTEGER NOT NULL DEFAULT 0 CHECK (weekday_mask BETWEEN 0 AND 127),        -- bit0=Sun .. bit6=Sat
  end_type TEXT NOT NULL DEFAULT 'never' CHECK (end_type IN ('never','until','count')),
  until_at TEXT,                                                -- inclusive, when end_type='until'
  occurrence_count INTEGER CHECK (occurrence_count >= 1),       -- when end_type='count'
  focus_enabled INTEGER NOT NULL DEFAULT 0,
  focus_work_min INTEGER, focus_short_break_min INTEGER, focus_long_break_min INTEGER,
  focus_cycles INTEGER, focus_auto_continue INTEGER NOT NULL DEFAULT 1,
  updated_at TEXT NOT NULL,
  CHECK (weekday_mask = 0 OR freq = 'weekly'),
  CHECK ((end_type = 'until') = (until_at IS NOT NULL)),
  CHECK ((end_type = 'count') = (occurrence_count IS NOT NULL)),
  CHECK (freq IS NOT NULL OR end_type = 'never')
) STRICT;

CREATE TABLE places (                                           -- 1:1 with memories; stored + shown, never armed in v1
  memory_id TEXT PRIMARY KEY REFERENCES memories(id) ON DELETE CASCADE,
  name TEXT, lat REAL NOT NULL CHECK (lat BETWEEN -90 AND 90), lng REAL NOT NULL CHECK (lng BETWEEN -180 AND 180),
  radius_m REAL NOT NULL DEFAULT 200 CHECK (radius_m BETWEEN 25 AND 5000),
  event TEXT NOT NULL DEFAULT 'enter' CHECK (event IN ('enter','exit')),
  active INTEGER NOT NULL DEFAULT 1,
  updated_at TEXT NOT NULL
) STRICT;

CREATE TABLE completions (                                      -- per-occurrence completion for recurring memories
  id TEXT PRIMARY KEY,
  memory_id TEXT NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
  occurrence_at TEXT NOT NULL,                                  -- exact occurrence instant (UTC)
  completed_at TEXT NOT NULL,
  UNIQUE (memory_id, occurrence_at)
) STRICT;
CREATE INDEX completions_completed_at ON completions(completed_at);

CREATE TABLE attachments (
  id TEXT PRIMARY KEY,
  memory_id TEXT NOT NULL REFERENCES memories(id) ON DELETE CASCADE,
  kind TEXT NOT NULL CHECK (kind IN ('photo','audio','file','link')),
  name TEXT, mime TEXT, size_bytes INTEGER, sha256 TEXT,
  rel_path TEXT,                                                -- relative to <data>/attachments; NULL for links
  url TEXT, title TEXT,                                         -- links
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  CHECK ((kind = 'link' AND url IS NOT NULL AND rel_path IS NULL) OR (kind <> 'link' AND rel_path IS NOT NULL))
) STRICT;
CREATE INDEX attachments_memory ON attachments(memory_id, kind, sort_order);

CREATE TABLE focus_sessions (
  id TEXT PRIMARY KEY,
  memory_id TEXT REFERENCES memories(id) ON DELETE SET NULL,    -- NULL = quick focus
  phase TEXT NOT NULL CHECK (phase IN ('work','short_break','long_break')),
  planned_s INTEGER NOT NULL, elapsed_s INTEGER NOT NULL,
  state TEXT NOT NULL CHECK (state IN ('completed','stopped')),
  started_at TEXT NOT NULL, ended_at TEXT NOT NULL
) STRICT;
CREATE INDEX focus_sessions_started ON focus_sessions(started_at);

CREATE TABLE reminder_oneoffs (                                 -- extra OS notifications not derived from a schedule
  id TEXT PRIMARY KEY,
  kind TEXT NOT NULL CHECK (kind IN ('focus_phase','snooze')),
  memory_id TEXT REFERENCES memories(id) ON DELETE CASCADE,
  fire_at TEXT NOT NULL, title TEXT NOT NULL, body TEXT,
  created_at TEXT NOT NULL
) STRICT;
CREATE INDEX reminder_oneoffs_fire ON reminder_oneoffs(fire_at);   -- rows older than 1 day are pruned by maintenance

CREATE TABLE settings (key TEXT PRIMARY KEY, value_json TEXT NOT NULL) STRICT;

CREATE TABLE activity (                                         -- append-only audit; capped to 50k rows by a maintenance job
  id TEXT PRIMARY KEY, at TEXT NOT NULL,
  actor TEXT NOT NULL,                                          -- 'ui' | 'cli' | 'mcp:<clientName>' | 'system'
  entity TEXT NOT NULL, entity_id TEXT NOT NULL,
  op TEXT NOT NULL CHECK (op IN ('create','update','delete','complete','reopen')),
  summary TEXT NOT NULL
) STRICT;
CREATE INDEX activity_at ON activity(at DESC);

-- search (see 05-search-attachments-map.md)
CREATE VIRTUAL TABLE memory_fts USING fts5(
  memory_id UNINDEXED, title, note, checklist, tags, mind,
  tokenize = 'unicode61 remove_diacritics 2', prefix = '2 3'
);
CREATE TABLE embeddings (
  memory_id TEXT PRIMARY KEY REFERENCES memories(id) ON DELETE CASCADE,
  model TEXT NOT NULL, dims INTEGER NOT NULL, vector BLOB NOT NULL,   -- float32 little-endian, L2-normalized
  text_hash TEXT NOT NULL, updated_at TEXT NOT NULL
) STRICT;
```

Derived rules enforced by services (not SQL): `status='completed'` ⇒ `completed_at` set; recurring memories complete **per
occurrence** via `completions`, and the memory flips to `completed` only when the series has ended and every occurrence is
completed (or the user completes the whole series explicitly); `auto_complete_on_checklist` completes the memory when all
items are done; `schedules.fire_at` must be in the future at creation unless the schedule is recurring or explicitly backdated.

`MemoryService.List` filters: `mind_id` (+`include_descendants`, `inbox_only`), `status`, `pinned`, `tag_ids`, `due_from`,
`due_to`, `updated_from`, `updated_to`, `has_schedule`, `has_place`, `query` (FTS), `order` (`updated`/`due`/`manual`/`created`),
`limit` (default 50, max 500), `cursor`.

Typed settings keys (`SettingsService`): `appearance.theme` (`system|dark|light` — v1 ships dark only; key reserved),
`notifications.sound`, `notifications.allDayTime` (default `09:00`), `notifications.snoozeMinutes` (default 10),
`focus.work|shortBreak|longBreak|cycles|autoContinue|sounds|notifications`, `map.online` (bool), `map.provider`,
`search.semantic.*`, `agents.mcpPort`, `agents.mcpEnabled`, `agents.allowFileAttach`, `app.keepRunningInBackground`.

## Error model

Connect codes: `INVALID_ARGUMENT` (details: list of `{field, reason}`), `NOT_FOUND`, `ALREADY_EXISTS`,
`FAILED_PRECONDITION` (rev conflict: details carry the current entity; also "mind has cycle", "schedule in the past"),
`UNAUTHENTICATED`, `RESOURCE_EXHAUSTED` (attachment too large), `UNAVAILABLE` (embedding provider down), `INTERNAL`.
MCP maps them to tool errors with a short actionable sentence (see [04-mcp.md](04-mcp.md)).

## Domain ports (Go)

Each `domains/<x>` declares the repository interface it needs (e.g. `memory.Repository`, `schedule.Repository`,
`search.Index`, `attachments.Store`, `clock.Clock`, `ids.Generator`), plus an in-memory fake under `domains/<x>/fake` for tests.
`providers/sqlite` implements them; `compositions/core` wires everything. W0-CONTRACTS commits the interfaces so W1-DOMAIN
(fakes) and W1-STORE (SQLite) can proceed in parallel without waiting on each other.
