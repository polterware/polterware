# Pin the Electron runtime required by the native build

Owner: integrator / W3-PACKAGING.

`pnpm install --lockfile=false` resolved desktop Electron `^44.4.5` to 44.5.1. `native/scripts/build.sh` explicitly rejected it with `Expected Electron 44.4.5, got 44.5.1`. The E2E build succeeded after installing 44.4.5 into ignored test build tooling and relinking the local `node_modules/electron`; no tracked dependency was patched outside the permitted Playwright change.

Apply this exact manifest delta before regenerating the lockfile if the native script is intended to remain pinned:

```diff
--- a/apps/sparky-desktop/package.json
+++ b/apps/sparky-desktop/package.json
@@
-    "electron": "^44.4.5",
+    "electron": "44.4.5",
```

Alternatively the native owner can qualify 44.5.1 and remove the equality guard with evidence. W3-E2E does not make that product/native change. A frozen installation of the current lockfile already uses 44.4.5; regeneration must not silently break `prepare-e2e.sh`.
